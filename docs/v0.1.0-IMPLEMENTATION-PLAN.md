## Executive Summary

v0.1.0 delivers the full vision of AgentScale - **queue-based autoscaling** that scales on actual work, not CPU metrics.

```bash
# Single execution (MVP - already done)
echo '{"query": "test"}' | agentscale run ./agent

# Local server with autoscaling (v0.1.0 - to build)
agentscale serve ./agent --port=8080
curl localhost:8080/run -d '{"query": "test"}'
# Workers scale automatically based on queue depth
```

**Why this matters**: Traditional autoscaling (CPU/memory) is reactive and slow. Queue-based scaling is predictive - we know exactly how many tasks are waiting and can scale instantly.

---

## Current State vs Target State

### Current MVP (v0.0.x)
```
CLI → Runner → Generator → Proxy → Isolate → Agent
         ↓
    Single execution, exits after each run
```

### Target v0.1.0
```
HTTP Request → Queue → WorkerPool → Runner → Agent
                 ↑           ↑
           QueueMetrics  Autoscaler
               (queue-based scaling)
```

**Key Difference**: MVP runs one task and exits. v0.1.0 runs a persistent server that handles many concurrent requests with automatic worker scaling.

## Core Concepts

### 1. Queue-Based Scaling (The Innovation)

Traditional scaling:
```
CPU > 80% → scale up (reactive, slow, often wrong for AI workloads)
```

AgentScale scaling:
```
(pending_tasks + processing_tasks) / workers > threshold → scale up
```

**Why it's better**:
- AI agents are I/O bound (waiting for LLM APIs), not CPU bound
- We know exactly how much work is queued
- Scaling is instant and predictive

### 2. Tier-Based SLAs

Different users get different scaling behavior:

| Tier | Min Workers | Max Workers | Scale Up Delay | Scale Down Delay |
|------|-------------|-------------|----------------|------------------|
| free | 1 | 2 | 30s | 2min |
| pro | 1 | 10 | 15s | 1min |
| teams | 2 | 50 | 10s | 30s |

### 3. Worker Pool Pattern

```go
// Get a worker (blocks if none available)
worker := pool.GetIdleWorker(ctx)

// Execute the task
result := worker.Execute(ctx, input)

// Return worker to pool
pool.ReturnWorker(worker)
```

Workers are reused across requests for efficiency.

```go
// Worker - Individual execution unit
type Worker interface {
    ID() string
    AgentID() string
    IsIdle() bool
    Execute(ctx context.Context, input []byte) (*Result, error)
    Shutdown(ctx context.Context) error
    Health() HealthStatus

// WorkerPool - Manages pool of workers for an agent
type WorkerPool interface {
    AgentID() string
    Size() int
    DesiredSize() int
    SetDesiredSize(size int)
    GetIdleWorker(ctx context.Context) (Worker, error)  // BLOCKS until available
    ReturnWorker(worker Worker)
    Shutdown(ctx context.Context) error
}

// Autoscaler - Makes scaling decisions based on queue metrics
type Autoscaler interface {
    Start(ctx context.Context) error
    Stop() error
    RegisterPool(agentID string, pool WorkerPool, policy ScalingPolicy)
    RegisterQueueMetrics(agentID string, metrics QueueMetrics)
}

// QueueMetrics - Input for scaling decisions
type QueueMetrics interface {
    PendingTasks() int      // Tasks waiting in queue
    ProcessingTasks() int   // Tasks currently being processed
    QueueLength() int       // Total = pending + processing
}
```

```go
type ScalingPolicy struct {

    ScaleDownThreshold float64      // e.g., 0.5 (scale down when util < 0.5)
    ScaleUpDelay      time.Duration // Cooldown after scaling up
    ScaleDownDelay    time.Duration // Cooldown after scaling down
```

### Phase 3: Autoscaler Implementation

**Goal**: Port the queue-based autoscaling algorithm.

**File to Create**:
```

```

**BasicAutoscaler Structure**:
```go
type BasicAutoscaler struct {
    pools         map[string]WorkerPool
    policies      map[string]ScalingPolicy
    metrics       map[string]QueueMetrics
    lastScaleTime map[string]time.Time

    interval      time.Duration  // Check interval (default: 5s)
    globalMax     int            // System-wide worker limit

    mu     sync.RWMutex
    ctx    context.Context
    cancel context.CancelFunc
}
```

**Core Scaling Algorithm**:
```go
func (a *BasicAutoscaler) GetScalingDecision(agentID string) int {
    metrics := a.metrics[agentID]
    pool := a.pools[agentID]
    policy := a.policies[agentID]

    pending := metrics.PendingTasks()
    processing := metrics.ProcessingTasks()
    current := pool.Size()

    // Calculate utilization
    utilization := float64(pending + processing) / float64(current)

    // Scale UP decision
    if utilization > policy.ScaleUpThreshold {
        target := int(math.Ceil(float64(pending+processing) / policy.TargetUtilization))
        return min(target, policy.MaxWorkers)
    }

    // Scale DOWN decision
    if utilization < policy.ScaleDownThreshold {
        target := int(math.Ceil(float64(pending+processing) / policy.TargetUtilization))
        return max(target, policy.MinWorkers)
    }

    return current  // No change
}
```

**Scaling Loop** (runs every 5 seconds):
```go
func (a *BasicAutoscaler) scalingLoop() {
    ticker := time.NewTicker(a.interval)
    defer ticker.Stop()

    for {
        select {
        case <-ticker.C:
            a.mu.RLock()
            for agentID := range a.pools {
                if a.canScale(agentID) {
                    desired := a.GetScalingDecision(agentID)
                    current := a.pools[agentID].Size()

                    if desired != current {
                        log.Printf("[autoscaler] %s: scaling %d → %d", agentID, current, desired)
                        a.pools[agentID].SetDesiredSize(desired)
                        a.lastScaleTime[agentID] = time.Now()
                    }
                }
            }
            a.mu.RUnlock()

        case <-a.ctx.Done():
            return
        }
    }
}
```

**AgentQueue Structure**:
```go
type AgentQueue struct {
    agentID    string
    requests   chan *QueuedRequest   // Pending requests (buffered)
    processing sync.Map              // Currently processing requests
    maxSize    int

    // Metrics
    totalEnqueued   int64  // atomic
    totalProcessed  int64  // atomic
    totalFailed     int64  // atomic
}

type QueuedRequest struct {
    ID         string
    Input      []byte
    Context    context.Context
    ResponseCh chan *QueuedResponse
    QueuedAt   time.Time
}

type QueuedResponse struct {
    Result   *proxy.Result
    Error    error
    Duration time.Duration
}
```

**QueueMetrics Implementation** (used by autoscaler):
```go
func (q *AgentQueue) PendingTasks() int {
    return len(q.requests)  // Tasks waiting in channel
}

func (q *AgentQueue) ProcessingTasks() int {
    count := 0
    q.processing.Range(func(_, _ interface{}) bool {
        count++
        return true
    })
    return count
}

func (q *AgentQueue) QueueLength() int {
    return q.PendingTasks() + q.ProcessingTasks()
}
```

**Enqueue with Backpressure**:
```go
func (q *AgentQueue) Enqueue(ctx context.Context, input []byte) (*QueuedResponse, error) {
    req := &QueuedRequest{
        ID:         uuid.New().String(),
        Input:      input,
        Context:    ctx,
        ResponseCh: make(chan *QueuedResponse, 1),
        QueuedAt:   time.Now(),
    }

    // Try to enqueue (with backpressure)
    select {
    case q.requests <- req:
        atomic.AddInt64(&q.totalEnqueued, 1)
    case <-ctx.Done():
        return nil, ctx.Err()
    }

    // Wait for response
    select {
    case resp := <-req.ResponseCh:
        return resp, nil
    case <-ctx.Done():
        return nil, ctx.Err()
    }
}
```

```go
func NewServer(cfg *config.AgentConfig, tier string, addr string) (*Server, error) {
    // 1. Create queue (100 max pending requests)
    q := queue.NewAgentQueue(cfg.Name, 100)

    // 2. Create worker spawner (uses existing Runner)
    spawner := scaling.NewAgentSpawner(cfg)

    // 3. Get tier policy
    policy := scaling.GetTierPolicy(tier)

    // 4. Create worker pool
    pool := scaling.NewWorkerPool(cfg.Name, spawner, policy)

    // 5. Create autoscaler
    autoscaler := scaling.NewAutoscaler()
    autoscaler.RegisterPool(cfg.Name, pool, policy)
    autoscaler.RegisterQueueMetrics(cfg.Name, q)

    return &Server{
        agentID:    cfg.Name,
        config:     cfg,
        queue:      q,
        pool:       pool,
        autoscaler: autoscaler,
        addr:       addr,
    }, nil
}
```

**HTTP Handlers**:
```go
// POST /run - Execute agent
func (s *Server) handleRun(w http.ResponseWriter, r *http.Request) {
    // Read input
    input, err := io.ReadAll(r.Body)
    if err != nil {
        http.Error(w, "failed to read body", http.StatusBadRequest)
        return
    }

    // Enqueue and wait (blocks until complete)
    resp, err := s.queue.Enqueue(r.Context(), input)
    if err != nil {
        http.Error(w, err.Error(), http.StatusServiceUnavailable)
        return
    }

    // Return response
    w.Header().Set("Content-Type", "application/json")
    if resp.Error != nil {
        w.WriteHeader(http.StatusInternalServerError)
    }
    json.NewEncoder(w).Encode(resp.Result)
}

// GET /health - Health check
func (s *Server) handleHealth(w http.ResponseWriter, r *http.Request) {
    w.WriteHeader(http.StatusOK)
    w.Write([]byte("ok"))
}

// GET /status - Detailed status
func (s *Server) handleStatus(w http.ResponseWriter, r *http.Request) {
    status := map[string]interface{}{
        "agent":      s.agentID,
        "workers":    s.pool.Size(),
        "pending":    s.queue.PendingTasks(),
        "processing": s.queue.ProcessingTasks(),
    }
    json.NewEncoder(w).Encode(status)
}
```

**Request Processing Loop**:
```go
func (s *Server) processRequests(ctx context.Context) {
    for {
        select {
        case req := <-s.queue.Requests():
            // Get idle worker (blocks if needed)
            worker, err := s.pool.GetIdleWorker(ctx)
            if err != nil {
                req.ResponseCh <- &queue.QueuedResponse{Error: err}
                continue
            }

            // Mark as processing
            s.queue.MarkProcessing(req.ID)

            // Execute in goroutine
            go func(w scaling.Worker, r *queue.QueuedRequest) {
                defer s.pool.ReturnWorker(w)
                defer s.queue.MarkDone(r.ID)

                result, err := w.Execute(r.Context, r.Input)
                r.ResponseCh <- &queue.QueuedResponse{
                    Result:   result,
                    Error:    err,
                    Duration: time.Since(r.QueuedAt),
                }
            }(worker, req)

        case <-ctx.Done():
            return
        }
    }
}
```

```go
func serveCommand(args []string) {
    fs := flag.NewFlagSet("serve", flag.ExitOnError)
    port := fs.Int("port", 8080, "Port to listen on")
    tier := fs.String("tier", "free", "Scaling tier (free/pro/teams)")
    noIsolate := fs.Bool("no-isolate", false, "Disable isolation")
    fs.Parse(args)

    agentDir := fs.Arg(0)
    if agentDir == "" {
        fmt.Fprintln(os.Stderr, "Error: agent directory required")
        os.Exit(1)
    }

    // Load config
    cfg, err := config.Load(agentDir)
    if err != nil {
        fmt.Fprintf(os.Stderr, "Error loading config: %v\n", err)
        os.Exit(1)
    }

    // Create and start server
    addr := fmt.Sprintf(":%d", *port)
    srv, err := server.NewServer(cfg, *tier, addr)
    if err != nil {
        fmt.Fprintf(os.Stderr, "Error creating server: %v\n", err)
        os.Exit(1)
    }

    fmt.Printf("Starting server on %s for agent '%s' (tier: %s)\n", addr, cfg.Name, *tier)
    if err := srv.Start(); err != nil {
        fmt.Fprintf(os.Stderr, "Server error: %v\n", err)
        os.Exit(1)
    }
}
```

**Python CLI Wrapper** (`cli/agentscale/commands/serve.py`):
```python
import typer
import subprocess
import sys
from pathlib import Path

def serve_agent(
    agent_path: str = typer.Argument(..., help="Path to agent directory"),
    port: int = typer.Option(8080, "--port", "-p", help="Port to listen on"),
    tier: str = typer.Option("free", "--tier", "-t", help="Scaling tier (free/pro/teams)"),
    no_isolate: bool = typer.Option(False, "--no-isolate", help="Disable isolation"),
):
    """Start HTTP server for an agent with autoscaling."""

    # Find runtime binary
    runtime_path = find_runtime_binary()

    # Build command
    cmd = [runtime_path, "serve", agent_path, f"--port={port}", f"--tier={tier}"]
    if no_isolate:
        cmd.append("--no-isolate")

    # Run server (blocks until interrupted)
    try:
        subprocess.run(cmd, check=True)
    except KeyboardInterrupt:
        print("\nShutting down...")
    except subprocess.CalledProcessError as e:
        sys.exit(e.returncode)
```
